# Transformer Language Model

A high-performance transformer-based language model implementation with support for distributed training and inference.

## Features

- **Modular Architecture**: Clean separation of model components
- **Distributed Training**: Support for DDP and FSDP
- **Flexible Configuration**: JSON-based configuration system
- **Inference Capabilities**: Text generation and prediction
- **Checkpointing**: Automatic model saving and loading

## Installation

```bash
pip install -r requirements.txt
```
